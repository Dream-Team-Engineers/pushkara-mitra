# Temporary logo and app icon

**Status: TEMPORARY, NEEDS REVIEW.** Used until final brand work is done (owner decision, 2026-11-15).

- **Home logo:** `logo-lockup-source.jpg` (owner file `pmlogo.jpeg`: pilgrim, ghat, sun and river emblem with the "Pushkara Mitra" wordmark). The Home screen shows the **emblem only** (`web/public/hero-logo.png`, cropped from the top of the file) on a white card, because the app already prints its own name and tagline in Telugu, Hindi and English. The full lockup stays available for the Play Store listing or a splash screen.
- **App icon and header mark:** `icon-goddess-source.jpg` (owner file `iconwithgoddess.png`, flattened on black). A square crop of the goddess and lotus, without the script wordmark (it is unreadable at icon sizes and masks would cut it) and without the glass frame, gives `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` (180 px), `logo-96.png` (header) and `icon-maskable-512.png` (artwork at 76% on dark navy so Android masks do not cut it). Colours reduced to 192 to keep the offline cache small.
- **Provenance:** both files were supplied by the owner on 2026-11-15 and look AI-generated. The tool, prompts, terms of use and rights holder are **not recorded and not reviewed**. The icon shows a deity; whether that suits a public event app, and how the Play Store and the organisers see it, is an owner decision. Not cleared for the store listing, advertising or a trademark filing (OQ-016, `docs/legal/trademark-review.md`).
- **Replacing:** crop a square, write the five icon files above, run `npm run build:web`. Do not put sources in `dist/`, which is rebuilt and not tracked.
