# Internationalisation

Telugu is the primary language; English is secondary. Hindi and others are out of scope until decided.

## Rules

1. **Telugu first.** The default locale is `te`. English is the fallback, never the other way round.
2. **No hard-coded user-facing strings.** All text lives in locale catalogues keyed by ID. The PR checklist asks for this on every pull request.
3. **Native review.** Telugu text is reviewed by a native speaker before release. Machine translation is a draft only.
4. **Layout.** Allow for longer strings and Telugu script height. Test at 200% text size.
5. **Fonts.** Use a font with full Telugu coverage and a licence on the allow-list (see [asset-permissions](legal/asset-permissions.md)). Subset it to meet the [performance budget](performance-budget.md).
6. **Numbers, dates and times** use the `Asia/Kolkata` time zone and the locale formatters, never string concatenation.
7. **Legal text** (notices, consent, government disclaimer) is approved by counsel in every language we ship.

## Status

No catalogue exists yet. The catalogue format and tooling are chosen in M1.
