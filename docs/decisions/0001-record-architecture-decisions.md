# 0001. Record architecture decisions

Status: Accepted (adopted by Kickoff Prompt V1)
Date: 2026-11-02

## Context

The project has legal, privacy and safety consequences. Decisions must be explainable months later, especially to counsel and auditors.

## Decision

We record significant decisions as numbered ADRs in `docs/decisions/` with Status, Context, Decision and Consequences. Statuses: Proposed, Accepted, Superseded. Open questions that need an owner live in [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md).

## Consequences

- Reversals are new ADRs, not edits.
- ADRs 0004 to 0007 start as Proposed and need acceptance at the M0 gate.
